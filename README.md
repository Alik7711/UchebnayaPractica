## 📂 Структура репозитория

**В репозитории представлены лабораторные работы:**

- *RefactoringLabWinForms* — лабораторная работа по рефакторингу WinForms-приложения  
- *SimpleCalculatorWinForms* — проект калькулятора на WinForms  
- *ЛБ Точки останова* — лабораторная работа по использованию точек останова и отладке  
- *ЛБ ЧЯ* — лабораторная работа по методу «Чёрного ящика»  
- *Отчет по практике* — документация и отчет по учебной практике  
- *Работа с командами Git* — практическая работа по использованию Git-команд  
- *Чёрный ящик АТС* — тестирование АТС методом «Чёрного ящика»  
- *Чёрный ящик Калькулятор* — тестирование калькулятора методом «Чёрного ящика»
